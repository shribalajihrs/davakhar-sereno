# Davakhar Sereno

A responsive, static landing page for the Davakhar Sereno residential project.

## Preview

Open `index.html` directly, or serve this directory with any static web server. The page has no build step or package dependencies.

The enquiry form opens a pre-filled WhatsApp message to the sales number. The visitor must press **Send** in WhatsApp to submit it.

## Publishing

This site is configured for GitHub Pages from the `main` branch, with `davakharsereno.com` as its custom domain. Configure the domain's DNS to point to GitHub Pages before enabling HTTPS. See [GitHub's custom domain documentation](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site).
